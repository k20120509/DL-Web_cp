## V2.5 (Current / 当前版本 - 2026-07-28)

### Major Updates / 重大更新

1. **Proxy Pool Rewritten / 重写代理池系统**
   - 8+ online proxy sources (proxyscrape, openproxylist, github, etc.) / 8+ 在线代理源
   - Concurrent testing of 80 proxies / 并发测试 80 个代理
   - Dynamic switching and priority management / 动态切换和优先级管理
   - Real-time best proxy latency display / 实时显示最优代理延迟

2. **New Features / 新功能**
   - Resume download: continue after interruption / 断点续传：下载中断后可继续
   - Multi-process concurrent download: faster speed / 多进程并发下载：提高下载速度
   - Auto delete incomplete files on exit / 未完成视频退出时自动删除
   - Open folder and locate file after download / 下载完成后自动打开文件夹定位文件
   - Real-time progress bar / 实时进度条显示

3. **Supported Platforms / 支持平台**

   - Douyin / TikTok China (抖音)
   - Twitter / X
   - Direct video links (直链视频)

4. **User Experience / 用户体验**
   - README reading confirmation prompt / README 阅读确认提示
   - Detailed progress and status feedback / 详细的进度和状态反馈

## Installation / 安装说明

1. Download the latest version from Releases / 从 Releases 下载最新版本
2. Extract the ZIP file / 解压 ZIP 文件
3. Run the .exe file / 运行 .exe 文件
4. Follow the on-screen instructions / 按照屏幕提示操作

## Notes / 注意事项

- If Windows SmartScreen warns, click "More info" -> "Run anyway" / 如果 Windows SmartScreen 警告，点击"更多信息" -> "仍要运行"
- For digital signature verification, install the included .cer certificate / 如需验证数字签名，请安装附带的 .cer 证书
