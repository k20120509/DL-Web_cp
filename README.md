## ⚠️ 重要声明 / IMPORTANT

本程序已使用 **Windows 自签名证书**（CN=Web CP Tools, O=k20120509）签名。

由于是开发者自签证书，**首次下载**在部分电脑可能触发：
- Windows SmartScreen 拦截
- 360、电脑管家、火绒等误报

### 解决方案（任选其一）

1. **安装签名证书（推荐）**：解压 → 双击 `webcp_signing.cer` → "安装证书" → 选"受信任的根证书颁发机构" → 完成
2. **添加白名单**：在杀毒软件中将 `video_downloader.exe` 加入信任列表
3. **临时关闭杀毒软件**：运行前关闭 360/电脑管家/火绒等

## 快速开始

### 第一步：下载和解压

1. 访问 [GitHub Releases](https://github.com/k20120509/DL-Web_cp/releases/tag/V2.5)
2. 下载 `video_downloader_v2.5.exe`
3. 放到任意文件夹（如 `D:\Tools\DL-Web_cp\`）

### 第二步：安装签名证书（必做）

1. 双击 `webcp_signing.cer` 文件
2. 点击"安装证书"
3. 选择"本地计算机" → 下一步
4. 选择"将所有的证书放入下列存储" → "受信任的根证书颁发机构"
5. 点击"下一步" → "完成"
6. 重启电脑（或刷新系统缓存）

### 第三步：运行程序

1. 双击 `video_downloader_v2.5.exe`
2. 阅读欢迎界面提示
3. 输入 `y` 确认已阅读文档
4. 开始使用！

## 详细使用教程

### 3.1 初始化代理池（首次使用必选）

代理池用于加速外网视频下载（如 YouTube）。**即使只下载 B 站视频，也建议初始化**。

```
请选择操作:
  [1] 单个视频下载
  [2] 批量视频下载
  [3] 初始化代理池 ← 选择这个！
  [4] 查看已使用的代理
  [0] 退出

请输入选项: 3
```

程序将自动：
1. 从多个在线源获取代理列表
2. 并发测试 80 个代理的可用性
3. 过滤出可用代理
4. 按延迟排序，选择最优代理

**耗时约 20-40 秒，请耐心等待**。

### 3.2 下载单个视频

```
请选择操作: 1
请输入视频URL: https://www.bilibili.com/video/BV1xx411c7mu

请选择清晰度:
  [1] 360P
  [2] 480P
  [3] 720P (推荐)
  [4] 1080P
  [5] 4K
请选择 (默认3): 3

请输入保存目录 (默认 ./downloads): D:\Videos\

下载成功！
文件: xxx.mp4
大小: 49.6MB
路径: D:\Videos\xxx.mp4
```

**支持的 URL 格式：**
- B 站视频页：`https://www.bilibili.com/video/BV1xx411c7mu`
- B 站 BV 号：`BV1xx411c7mu`
- B 站短链接：`https://b23.tv/xxxxx`
- YouTube 链接：`https://www.youtube.com/watch?v=xxxxx`
- YouTube 短链：`https://youtu.be/xxxxx`
- 直链视频：`https://example.com/video.mp4`

### 3.3 批量下载多个视频

```
请选择操作: 2
请输入视频URL列表，每行一个，输入空行结束:
> https://www.bilibili.com/video/BV1xx411c7mu
> https://www.bilibili.com/video/BV1yy411c7nv
> https://www.youtube.com/watch?v=xxxxx
> （空行结束）

共 3 个视频
...
下载完成统计:
  成功: 3 个
  失败: 0 个
  总大小: 125.3MB
  保存目录: D:\Videos
```

**批量下载支持 3 路并发**，速度更快。

### 3.4 查看代理池状态

```
请选择操作: 4

当前可用代理 (5 个):
--------------------------------------------------
  ✅ 1. 1.2.3.4:8080 (延迟: 0.52s, 成功: 15)
  ✅ 2. 5.6.7.8:8080 (延迟: 1.23s, 成功: 8)
  ...
--------------------------------------------------
🏆 最优: 1.2.3.4:8080
```

## 功能特性

### 1. 稳定代理池（V2.5 核心功能）

- **多源获取**：从 8+ 个知名免费代理源自动获取
- **严格测试**：每个代理经过 3 层验证
  - 代理连通性测试
  - 目标网站可访问性测试
  - 响应延迟测量
- **动态切换**：下载失败时自动切换到下一个代理
- **优先级管理**：成功的代理提升优先级，失败的降低优先级
- **自动清理**：失败 3 次的代理自动移除

### 2. 断点续传

- 下载中断后自动保存进度
- 进度保存到 `%TEMP%\dl_web_cp\` 目录
- 下次下载自动从断点继续
- 支持网络中断、程序崩溃后的恢复

### 3. 智能文件管理

- **自动清理**：未完成的临时文件在退出时自动删除
- **自动定位**：下载成功后自动打开文件夹并选中文件
- **进度持久化**：下载进度定期保存，防止意外丢失

### 4. 并发批量下载

- 支持同时下载 3 个视频
- 实时显示每个视频的下载状态
- 失败不影响其他视频的下载

### 5. 多平台支持

- B 站（哔哩哔哩）：全功能支持
- YouTube：通过代理池支持
- 通用直链：支持 mp4/webm/flv/mkv 等

### 6. 多清晰度支持

- 360P（流畅）
- 480P（清晰）
- 720P（高清，推荐）
- 1080P（超清）
- 4K（蓝光）
- 自动降级机制：高清晰度不可用时自动尝试低清晰度

## 常见问题解答

### Q1: 双击 exe 没有反应？

**A**: 可能是杀毒软件拦截了。请：
1. 检查杀毒软件隔离区
2. 临时关闭杀毒软件后重试
3. 或安装签名证书（见"重要声明"部分）

### Q2: B 站视频下载失败？

**A**: 可能的原因：
1. 视频已删除或设置了地区限制
2. 网络不稳定
3. 清晰度选择太高（如 4K 在非大会员账号可能失败）

**解决方法：**
1. 尝试降低清晰度（720P 或 480P）
2. 检查 URL 是否正确
3. 稍后重试

### Q3: YouTube 视频下载失败？

**A**: 必须先初始化代理池！
1. 运行程序
2. 选择 [3] 初始化代理池
3. 等待初始化完成
4. 再下载 YouTube 视频

如果代理池初始化后仍失败，可能是：
- 网络环境限制了外网访问
- 所有可用代理都无法访问 YouTube

### Q4: 下载中断了怎么办？

**A**: 本程序支持断点续传！
1. 重新运行程序
2. 输入相同的 URL 和保存路径
3. 程序会自动从上次中断的位置继续下载

### Q5: 下载完成后文件在哪里？

**A**: 
1. 下载成功后会自动打开文件夹并选中文件
2. 如果你关闭了弹窗，可以在程序中看到保存的路径
3. 默认保存路径是 `./downloads/`（相对于 exe 所在目录）

### Q6: 如何卸载/清理？

**A**: 
1. 删除 `video_downloader_v2.5.exe`
2. 删除下载的视频文件夹
3. 删除临时文件目录：`%TEMP%\dl_web_cp\`
4. 如需移除证书：
   - 打开"运行" → `certmgr.msc`
   - 找到"受信任的根证书颁发机构"
   - 删除 `Web CP Tools` 证书

### Q7: 代理池获取的代理能用吗？

**A**: 
- 代理池从多个知名源获取代理
- 经过严格测试（连通性、延迟、可用性）
- 只有通过测试的代理才会保留
- 但免费代理可能会失效，建议定期初始化
